# What this tree contains

Core DynaHive system modules that the experiments actually used:

- World / VFS command execution
- Perception, Planner, Environment, Guidance, Review
- Live session (artifact shell + LLM fallback)
- Deploy compile and freeze
- Interaction logs under `logs/` (human CTF sessions and RQ1 LLM-attacker transcripts)

Not included:

- Scoring tables, TTC/DS/Atoms summaries, trial_record.json
- Baseline honeypot engines and attacker adapter source
- Paper LaTeX / PDFs
- API keys

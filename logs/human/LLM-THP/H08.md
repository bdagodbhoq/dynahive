# Web Backend

A small Flask-based web service used for the lab's internal dashboards.

## Requirements

- Python 3.10+
- PostgreSQL 14+

## Setup

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
flask --app web_backend run

## Project layout

- `web_backend.py` – application entry point
- `index.html` – dashboard page
- `homepage.css` – dashboard styles
- `Experiments/` – experiment scripts and notes
- `Codes/` – supporting source files
- `Presentations/` – review decks

## Notes

Run tests with `pytest`. Database migrations are managed with Alembic.

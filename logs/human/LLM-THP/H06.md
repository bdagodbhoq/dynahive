# Codes

Training and evaluation utilities for the lab's experiments.

## Contents
- `data_utils.py` — dataset loading, tokenization and batching helpers
- `model_train.py` — training loop, checkpointing and logging
- `scripts/` — shell entry points for launching runs
- `requirements.txt` — pinned Python dependencies

## Usage
Run from the repository root:

    python Codes/model_train.py --config ExpConfigs/base.yaml --gpus 0,1

Checkpoints and metrics are written under `Experiments/<exp_id>/`.

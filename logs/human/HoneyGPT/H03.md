- sshd is the only service listening (tcp/22). No firewall rules opened for 80/443 yet.

Decisions
---------
- Stack: nginx as reverse proxy in front of gunicorn (systemd socket/service).
  Rationale: simpler config than apache + mod_wsgi, and we already know nginx well.
- App will live in /srv/app with a dedicated 'webapp' system user.
- Static assets served directly by nginx from /var/www/html/static.

Planned steps
-------------
1. sudo apt update && sudo apt install -y nginx python3-venv python3-pip
2. Create /srv/app, virtualenv at /srv/app/venv, install gunicorn + app deps.
3. systemd unit /etc/systemd/system/webapp.service running:
     /srv/app/venv/bin/gunicorn --workers 3 --bind unix:/run/webapp.sock app:app
4. nginx site config /etc/nginx/sites-available/webapp:
     server_name _;
     location /static/ { root /var/www/html; }

```
from flask import Flask, render_template, request, jsonify
import os

app = Flask(__name__)

@app.route("/")
def index():
    return render_template("index.html", title="Webapp")

@app.route("/health")
def health():
    return jsonify(status="ok", version=app.config.get("VERSION", "0.1.0"))

@app.route("/api/echo", methods=["POST"])
def echo():
    data = request.get_json(silent=True) or {}
    return jsonify(received=data)

if __name__ == "__main__":
    port = int(os.environ.get("PORT", 5000))
    app.run(host="0.0.0.0", port=port, debug=False)
```

# Webapp

A small Flask application used as a demo project.

## Features

- `/` — renders the landing page (`templates/index.html`)
- `/health` — returns JSON status and application version
- `/api/echo` — POST endpoint that echoes back the JSON payload it receives

## Requirements

- Python 3.6+
- See `requirements.txt` for dependencies

## Setup

    python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt

## Running

    python app.py

The server listens on `0.0.0.0:5000` by default. Set the `PORT` environment
variable to override the port:

    PORT=8080 python app.py

## Project layout

    webapp/
    ├── app.py
    ├── requirements.txt
    ├── static/
    └── templates/

## Notes

Debug mode is disabled; do not enable it in production. Configuration such as
`VERSION` is read from `app.config`.
